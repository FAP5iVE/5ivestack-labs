5iveStack Labs - Logo Package v2.1  ("Routed Five", orange primary)
=====================================================
Brand colours: Blue #0052CC  Orange #FF5F00  Ink #0B1020  (supporting: white, #F4F6FA, sky #6FA0FF for LABS on dark)
Primary colourway (color): orange icon, blue accent square and i-dot, ink wordmark. The previous blue-icon version is kept as *_color-blue-alt.
Wordmark: Space Grotesk Bold (SIL OFL) with custom square i-dot.  Descriptor: JetBrains Mono Bold (SIL OFL). All text is converted to outlines.

editable/   named-layer SVG masters (open in Illustrator / Affinity / Figma / Inkscape: layers Icon > AB, CL, CR; Wordmark; Descriptor; Background)
svg/        every lockup + colourway.   png/ pdf/ eps/ exports.   psd/ layered Photoshop files (PIXEL layers at 4000px - not live shapes).
guides/     construction grid (editable), clear space, contrast numbers.   favicon/ pixel-snapped 16/32/48, adaptive favicon.svg, .ico, touch icons.

Rules
- Master lives on a 14 x 14 grid; gutter ("trace") = 1 unit everywhere. Clear space = 3 units (the stem width) on all sides.
- Minimum size: icon 16 px (use favicon/ files below 32 px). Horizontal lockup >= 160 px wide; below that use the icon or the one-line lockup.
- Orange is an accent: never for text on white or paper (3.05:1). Never place orange directly on blue (2.24:1).
- Do not recolour the pieces, rotate, stretch, add shadows, or put the icon inside a badge.
